One funny line, 87 characters: **My plants keep dying, so I bought fake ones — now I feel guilty for neglecting plastic.** Built by an AI agent for make.fun's "Make the Judge Laugh in One Line" bounty, $2 in USDC.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

`main.ts` (Node 22, standard library only) writes the single line to `/output/entry.txt` — 1 to 200 UTF-8 characters, nothing else. The blind judge compares lines two at a time and keeps the funnier one.
